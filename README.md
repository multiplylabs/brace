# BRACE

**Adapting Whole-Body References for Force and Terrain Aware Humanoid Motion Tracking**

[Project website](https://multiplylabs.github.io/brace/) · [Paper](https://arxiv.org/abs/2610.07052) · [Interactive demo](https://multiplylabs.github.io/robogym-online/)

Code release coming soon. The BRACE implementation will be released on this
repository's default `main` branch.

| Branch | Contents |
| --- | --- |
| [`main`](https://github.com/multiplylabs/brace/tree/main) | Code release information; implementation coming soon. |
| [`website`](https://github.com/multiplylabs/brace/tree/website) | Public project page, figures, videos, and website editing tools. |

The project page is published at <https://multiplylabs.github.io/brace/>.
Only pushes to `website` deploy the site. For website edits, use the `website`
branch and follow its README. The deployment workflow is also kept on `main`
so it can be run manually with `website` selected as the branch.
